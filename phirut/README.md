# พิรุธ — ซีรีส์นักสืบสั้นแนวตั้ง (ร่างตัวอย่าง)

ซีรีส์คลิปสั้น 9:16 สำหรับ Facebook Reels / YouTube Shorts แนววิเคราะห์หลักฐาน เอกสาร และพิรุธ
คนดูต้องเห็นเบาะแสครบก่อนเฉลยเสมอ เพื่อให้เดาตามได้จริง (fair-play)

## ตัวเอก — ภาสกร มั่นคง ("กร")
- อายุ 38 อดีตนักบัญชีอาวุโสของบริษัท ธนากรวัสดุ จำกัด (บริษัทสมมติ)
- ถูกไล่ออกเพราะถูกกล่าวหาว่าโกงเงิน 2 ล้าน ตกงาน เป็นหนี้ จนล้มละลาย นามสกุล "มั่นคง" ประชดชีวิตตัวเอง
- ตกบันไดตึกเก่าตอนหนีคนทวงหนี้ หัวกระแทก โคม่า 3 วัน
- ตื่นมาพร้อมอาการ "อัจฉริยะเฉียบพลันหลังสมองบาดเจ็บ" (acquired savant syndrome มีเคสจริงในทางการแพทย์)
  เห็นรายละเอียดเล็ก ๆ ทั้งหมดในครั้งเดียว จำทุกตัวเลข และจับความไม่เข้ากันได้ทันที
- **ราคาที่ต้องจ่าย:** ทุกครั้งที่ "เห็น" จะปวดหัวข้างซ้ายรุนแรง อ่านสีหน้าคนไม่ค่อยออก จำวันเกิดแม่ตัวเองไม่ได้
- **ท่าประจำตัว:** เอานิ้วกดแผลเป็นที่ขมับซ้ายก่อนวิเคราะห์ (ใช้เป็นจุดตัดเข้าฉากวิเคราะห์ทุกตอน)
- **ประโยคประจำตัว:** "เอกสารไม่เคยโกหก… คนต่างหากที่ลืมว่ามันจำทุกอย่าง"

## โครงทุกตอน (60–90 วินาที)
1. **0–3 วิ ฮุก:** ประโยคช็อก + ภาพหลักฐานชิ้นเด่น
2. **ข้อเท็จจริง:** โชว์หลักฐานทีละชิ้น ค้างบนจอนานพอให้คนดูหยุดภาพแล้วหาเองได้
3. **ท้าคนดู:** "หลักฐานครบแล้ว คุณเห็นพิรุธกี่จุด?" (ใส่ช่วงเงียบ 1–2 วิ)
4. **กดขมับ:** ภาพเปลี่ยนเป็นขาวดำ เหลือแต่จุดพิรุธเป็นสีแดง
5. **เฉลยทีละข้อ:** วงแดงพร้อมเสียงปากกาเมจิก
6. **จบค้าง:** เบาะแสโยงไปตอนหน้า
