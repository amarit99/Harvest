# หวยใบที่ไม่ใช่ของฉัน — แคปชันสำหรับโพสต์

## EP.1 — ใบที่จองไว้
```
ขายลอตเตอรี่มาสามสิบปี… เพิ่งเคยเห็นใบที่ถูกรางวัลที่หนึ่งกับตาตัวเอง 🎫
แต่ใบนั้นไม่ใช่ของฉัน มันเป็นของลุงคนเก็บขยะที่จองไว้… แล้วหายตัวไป
หกล้านอยู่ในมือ ไม่มีใครรู้นอกจากฉันคนเดียว
หวยใบที่ไม่ใช่ของฉัน EP.1

#หวยใบที่ไม่ใช่ของฉัน #ซีรีส์สั้น #ถูกหวย #ละครคุณธรรม #ความซื่อสัตย์ #การ์ตูน
```

## EP.2 — ลูกชายขอ
```
"แม่จะคืนหกล้านให้คนเก็บขยะเหรอ! แม่บ้าไปแล้ว!" 💔
ลูกชายตะคอกใส่ฉันเป็นครั้งแรกในชีวิต… แล้วฉันก็ได้รู้ว่าเขาติดหนี้พนันสามแสน
พี่สะใภ้ยังมาขอซื้อหวยใบนั้นห้าแสน
หวยใบที่ไม่ใช่ของฉัน EP.2

#หวยใบที่ไม่ใช่ของฉัน #ซีรีส์สั้น #หนี้พนัน #โดนดูถูก #ละครคุณธรรม #ครอบครัว
```

## EP.3 — ตามหาลุงสม
```
"ต่อให้หกร้อยล้าน… ก็ต้องคืนเจ้าของจ้ะ" 🏥
ฉันขายสร้อยทองเส้นเดียวที่มี เพื่อจ่ายค่าห้องให้ลุงที่ยังไม่ฟื้น
แล้วตีสาม… หวยหกล้านก็หายไปจากลิ้นชัก พร้อมลูกชายของฉัน
หวยใบที่ไม่ใช่ของฉัน EP.3

#หวยใบที่ไม่ใช่ของฉัน #ซีรีส์สั้น #ความซื่อสัตย์ #น้ำตาซึม #ละครคุณธรรม #ถูกหวย
```

## EP.4 — ใบที่หายไป
```
ลูกชายยืนอยู่หน้าช่องขึ้นเงินรางวัลยี่สิบนาที… แล้วหันหลังกลับ 😭
"ผมเป็นลูกแม่… ผมโกงใครไม่ลง"
และฉันตอบพี่สะใภ้ที่ดูถูกฉันมาทั้งชีวิตว่า "ฉันอาจจะจน แต่ฉันนอนหลับสนิททุกคืน… พี่ล่ะ นอนหลับไหม"
หวยใบที่ไม่ใช่ของฉัน EP.4

#หวยใบที่ไม่ใช่ของฉัน #ซีรีส์สั้น #แม่ลูก #ตบหน้า #ละครคุณธรรม #ข้อคิด
```

## EP.5 — หกล้านของคนจน (ตอนจบ)
```
ฉันไม่ได้หกล้าน… แต่ฉันได้สิ่งที่มีค่ากว่านั้น 💛
หลานได้ทุนเรียนจนจบปริญญา ลูกชายได้ชีวิตใหม่ และลุงสมได้เจอลูกสาวในรอบยี่สิบปี
"ความซื่อสัตย์… ไม่มีราคา แต่มันมีค่าที่สุด"
หวยใบที่ไม่ใช่ของฉัน EP.5 (ตอนจบ)

#หวยใบที่ไม่ใช่ของฉัน #ซีรีส์สั้น #ตอนจบ #ละครคุณธรรม #ข้อคิดดีๆ #ความซื่อสัตย์
```
