# ไรเดอร์พันล้าน — แนวเรื่อง

> คำศัพท์ของเรื่องดูที่ [`GLOSSARY.md`](GLOSSARY.md)

## แนวคิดหลัก
- **แนว:** ประสบความสำเร็จแต่แกล้งจน + แฟนมีชู้ + โดนดูถูก + ละครคุณธรรม
- **โทน:** สะใจแต่ไม่ใจร้าย พระเอกเอาคืนด้วยความถูกต้อง ไม่ใช่ด้วยความแค้น
- **รูปแบบ:** คลิปแนวตั้ง 9:16 ตอนละประมาณ 3 นาที เรื่องนี้มี 5 ตอนแล้วจบ
- **การผลิต:** Claude ทำเองทั้งหมด
  - ภาพวาดด้วยโค้ด สไตล์หัวกลมตาจุด เส้นขอบหนา สีแบน (`tools/cartoon/`)
  - เสียงพูด เพลง และเสียงประกอบจาก ElevenLabs
- **โครงทุกตอน:** เปิดด้วยฉากถูกเหยียด → การ์ดเวลา → ฉากเอาคืนจากอนาคต → ย้อนกลับไปเล่าตั้งแต่ต้น → จบด้วยปมค้าง

## เรื่องย่อรายตอน
1. **ไรเดอร์ที่ถูกทิ้ง** ✅ [ข้อมูลตอน](episodes/EP01.json)
   เต้ไปส่งอาหารแล้วเจอมิ้นกับบอส มิ้นบอกเลิก บอสโยนเหรียญให้ก้มเก็บ คืนนั้นเลขาฯ โทรมาบอกว่าพรุ่งนี้บริษัทของบอสจะมาเสนองาน และเพิ่งเปิดเผยว่าเต้คือเจ้าของแอปส่งไว
   **ปมค้าง:** "พรุ่งนี้… ผมเข้าประชุมเอง"
2. **ห้องประชุม** ✅ [ข้อมูลตอน](episodes/EP02.json): บอสเดินเข้ามานำเสนอ แล้วเห็นเต้นั่งหัวโต๊ะ ข้อเสนอของดาวทองคือ**หักค่ารอบไรเดอร์**เพื่อเพิ่มกำไร เต้ปฏิเสธเพื่อไรเดอร์ ไม่ใช่เพื่อแก้แค้น บอสคุกเข่าขอโทษ แล้วถูกบริษัทตัวเองไล่ออก
   **ปมค้าง:** มิ้นเห็นข่าวว่าประธานส่งไวคือเต้
3. **แฟนเก่ากลับมา** ✅ [ข้อมูลตอน](episodes/EP03.json): มิ้นกลับมาขอคืนดี เต้ทดสอบเธอด้วยการยังใส่ชุดไรเดอร์ จนรู้ว่าเธอต้องการแค่เงิน ลุงชัยล้มป่วย เต้แอบจ่ายค่ารักษาให้โดยไม่บอกชื่อ
   **ปมค้าง:** บอสที่ตกงาน มาสมัครเป็นไรเดอร์ของส่งไว
4. **ไรเดอร์คนใหม่** ✅ [ข้อมูลตอน](episodes/EP04.json): บอสได้เจอทุกอย่างที่เคยทำกับคนอื่น ถูกลูกค้าดูถูก ตากฝน ถูกโยนเหรียญ คนที่ยื่นมือช่วยคือลุงชัย บอสเริ่มเปลี่ยน
   **ปมค้าง:** มิ้นจมหนี้ที่บอสก่อไว้ มายืนหน้าออฟฟิศส่งไว
5. **ค่ารอบใหม่ (ตอนจบ)** ✅ [ข้อมูลตอน](episodes/EP05.json): เต้เปิดตัวต่อหน้าไรเดอร์ทั้งศูนย์ ประกาศเพิ่มค่ารอบ และตั้งกองทุนสวัสดิการไรเดอร์ในชื่อลุงชัย บอสขอโทษอย่างจริงใจ เต้ให้โอกาสทำงานใหม่ มิ้นขอคืนดี เต้ปฏิเสธอย่างสุภาพ "ผมไม่ได้โกรธ… แต่ผมไม่ได้รักแล้ว"
   **ช็อตสุดท้าย:** เต้กับลุงชัยขี่มอเตอร์ไซค์ไปส่งอาหารด้วยกัน
   **ข้อคิด:** คนเราไม่ได้มีค่าเพราะงานที่ทำ
