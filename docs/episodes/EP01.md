# Harvest ตอนที่ 1 — "สิบเอ็ดกำมือ"

- **ความยาว:** ประมาณ 75 วินาที
- **อัตราส่วน:** 9:16 (แนวตั้ง)
- **เสียงบรรยาย:** ป้าแวว (หญิงวัย 50 กว่า เสียงแหบนิด ๆ พูดช้า เรียบ แต่มีหนาม)
- **เสียงตัวละครอื่น:** ภูมิ (เด็กผู้ชายวัยรุ่น เสียงแหบแห้ง เหนื่อย)
- **ภาพ:** ใช้คำบรรยายตัวละครและสไตล์จาก [`../VISUAL.md`](../VISUAL.md) ต่อท้ายทุก prompt

## เรื่องย่อ
ป้าแววจับได้ว่ามีคนขโมยข้าวในยุ้ง คนนั้นคือเด็กหนุ่มชื่อภูมิ เสียงของทั้งคู่ดึงผีรวงตัวหนึ่งเข้ามา
ภูมิฆ่ามันได้อย่างคล่องมือเกินกว่าเด็กเมืองทั่วไป ป้าแววตัดสินใจให้เขาอยู่ช่วยทำนา
แต่คืนนั้นเอง วิทยุในกระเป๋าของภูมิก็ส่งเสียงขึ้นมา
