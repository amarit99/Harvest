# ตาทอง — แนวเรื่อง

> เอกสารแนวเรื่องสำหรับซีรีส์ Facebook Reels / YouTube Shorts คำศัพท์ของเรื่องดูที่ [`GLOSSARY.md`](GLOSSARY.md)

## แนวคิดหลัก

- **แนว:** เอาคืน (โดนดูถูก → ได้พลัง → รวย → เอาคืน) ผสมแนว "ระบบ" แบบเกม
- **โทน:** สะใจ จังหวะเร็ว ทุกตอนต้องมีอย่างน้อยหนึ่งจังหวะที่คนดูสะใจ
- **ความยาว:** 12 ตอน จบสมบูรณ์ในซีซันเดียว
- **ฉากหลัง:** เมืองสมมติชานกรุง (ไม่ระบุสถานที่จริง)

## รูปแบบและการผลิต
- วิดีโอแนวตั้ง 9:16 ยาว 60–90 วินาที บุญเป็นผู้เล่าเรื่องบุรุษที่หนึ่ง และมีบทพูดโต้ตอบมากกว่าซีรีส์อื่น
- ภาพการ์ตูน 2D เวกเตอร์ตัวจิ๋ว (chibi) สร้างวิดีโอใน Google Flow ดู [`VISUAL.md`](VISUAL.md)
- **หน้าจอระบบ** (ป้ายราคา กรอบสีความหายาก ข้อความแจ้งเตือน) ใส่ตอนตัดต่อ ไม่ใส่ในภาพ AI และมีเสียง "ติ๊ง" ทุกครั้ง
- จบทุกตอนด้วยปมค้าง และคนที่เพิ่งเจอตอนนั้นเป็นตอนแรกต้องดูรู้เรื่อง

## ตัวละคร

### บุญ — ผู้เล่าเรื่อง
- ลูกเขยวัย 28 อาชีพรับซื้อของเก่า ขับรถกระบะเก่า ๆ
- ครอบครัวภรรยาเรียกเขาว่า "ไอ้บุญ" และดูถูกว่าเป็นคนเก็บขยะ
- ใจเย็น อดทน ไม่ชอบมีปัญหา แต่พอได้ระบบมา เขาเลือกเอาคืนอย่างเงียบ ๆ และฉลาด

### ฝน — ภรรยา
- รักและอยู่ข้างบุญจริง แต่ไม่กล้าขัดแม่
- เติบโตขึ้นระหว่างเรื่อง จนกล้ายืนข้างบุญต่อหน้าทุกคน (ตอน 11)

### แม่ยาย
- แม่ของฝนและแพรว งกและบ้าเงิน วัดค่าคนด้วยของที่เขาให้
- ในบทเรียกว่า "แม่" หรือ "แม่ยาย" เท่านั้น ไม่มีชื่อจริง

### เคน — พี่เขย (ศัตรูตัวสุดท้าย)
- สามีของแพรว อวดรวย คนในบ้านชมไม่ขาดปาก
- แท้จริงเป็นหนี้และโกงเงินคนอื่นมาตลอด

### แพรว — พี่สาวของฝน
- ภรรยาของเคน เริ่มจากดูถูกบุญ แล้วค่อย ๆ รู้ว่าสามีหลอกตัวเอง

## ระบบ

พลังแบบเกมที่**มีแค่บุญมองเห็น** ทำงานเมื่อบุญสวม**แว่น**กรอบทองเก่าที่รับซื้อมาจากบ้านคนตาย

### กฎ
1. ของทุกชิ้นที่บุญมองจะมี**ป้ายราคา**ลอยอยู่ พร้อมสี**ความหายาก**: เทา → เขียว → ฟ้า → ม่วง → ทอง
2. ลอตเตอรี่ใบที่จะถูกรางวัลจะมีป้ายบอกเงินรางวัล
3. ระบบ**เลื่อนขั้น**ได้ ยิ่งขั้นสูงยิ่งเห็นมากขึ้น

| ขั้น | เห็นอะไร |
|---|---|
| 1 | ป้ายราคาและความหายากของสิ่งของ |
| 2 | ของปลอมและตำหนิที่ซ่อนอยู่ |
| 3 | คำโกหก (ข้อความสีแดงขึ้นเหนือคนพูด) |
| 4 | ของที่ถูกซ่อนไว้ |
| 5 · **ตาทอง** | ความลับในใจคน |

## ตอนจบ
เคนถูกจับ แม่ยายมาขอโทษ บุญให้อภัยแต่ไม่กลับไปอยู่บ้านนั้น เขากับฝนเปิดร้านของเก่าของตัวเอง
**ช็อตสุดท้าย:** บุญถอดแว่นวางไว้บนโต๊ะในร้าน เขาไม่ต้องพึ่งระบบอีกแล้ว
