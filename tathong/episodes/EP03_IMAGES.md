# ตาทอง ตอนที่ 3 — รายการภาพที่ต้องสร้างใน Flow (ภาพนิ่ง 12 ภาพ + ตัวละครใหม่ 2 ภาพ)

## วิธีทำ (เหมือนตอน 2)

1. ใน Flow เลือก**สร้างภาพ** ตั้ง **9:16**
2. ทำทีละข้อ ตั้งแต่ 0a, 0b แล้ว P01 ถึง P12
3. **แนบภาพอ้างอิง**ตามที่ระบุไว้ ใช้ภาพเดิมจากตอนก่อน ส่วนตัวละครใหม่ใช้ภาพจากข้อ 0a และ 0b
4. ก๊อป prompt ในกล่องไปวางทั้งก้อน
5. ส่งภาพมาในแชตเรียงตามลำดับ P01 → P12 ภาพ 0a และ 0b ส่งมาด้วย

ข้อไหนไม่ผ่านหรือออกมาไม่ดี ข้ามไปก่อน แล้วบอกเลขข้อ
