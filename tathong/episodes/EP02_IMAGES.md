# ตาทอง ตอนที่ 2 — รายการภาพที่ต้องสร้างใน Flow (ภาพนิ่ง 12 ภาพ + ตัวละครใหม่ 1 ภาพ)

## วิธีทำ (ทำตามนี้อย่างเดียว)

1. ใน Flow เลือก**สร้างภาพ** (ไม่ใช่วิดีโอ) และตั้งอัตราส่วน **9:16**
2. ทำทีละข้อ ตั้งแต่ข้อ 0 ไปจนถึง P12
3. **แนบภาพอ้างอิง**ตามที่ระบุไว้ในแต่ละข้อ ใช้ภาพเดิมจากตอน 1 ทั้งหมด
4. ก๊อป prompt ในกล่องไปวางทั้งก้อน ไม่ต้องแก้อะไร
5. ได้ภาพที่ชอบแล้ว ตั้งชื่อไฟล์ตามรหัสข้อ (`P01.png` … `P12.png`) แล้วส่งมาในแชตทีเดียวทั้งหมด

ถ้าภาพไหนไม่ผ่านตัวกรอง หรือออกมาไม่ดี ข้ามไปก่อนได้ แล้วบอกผมว่าเป็นข้อไหน
